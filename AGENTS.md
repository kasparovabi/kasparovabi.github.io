# Portfolio conventions

This is the separate portfolio draft. Do not publish without user authorization.

User facing copy must not contain em dashes, en dashes, double hyphens or decorative dash separators. Use sentences, commas or other plain punctuation. This applies to titles, descriptions and project details. Code syntax, CSS custom properties, identifiers and URLs are not prose.

Keep actual interface captures and clearly labeled demo footage. Preserve screenshot fallbacks for projects without videos. Only the active preview should play; respect reduced motion and data saving preferences.

The project data generator must preserve media-manifest.json video assignments.
