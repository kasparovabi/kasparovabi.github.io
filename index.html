Rıfkı, ESP32-S3 desktop robot · the board browned out and boot looped, on battery, for a month

First guess
Servos stay passive during boot, so they cannot be the cause.
Signal
Watching the hardware: the servos twitch the instant the battery goes in.
Root cause
At reset the PWM pins float. Three SG90 servos each pull about 300 mA of inrush, and together with the WiFi power peak they collapse the boost rail.
Fix
Drive the servo and motor pins to OUTPUT LOW with pulldown in the first line of the board constructor.No hardware change. The twitching stopped and the screen came up on the first try.

Maarif Task Management

In production · Türkiye Maarif Vakfı, Directorate of Communications

Before it existed the director read every incoming email himself, decided who should do each job, then tracked every delivery personally. The system reads the mailbox, turns each message into a task definition with an LLM, assigns it, and shows the state of every job on an office TV board.

Symptom
Generated task documents drifted from the institution's templates, and a text diff showed nothing.
Root cause
The drift was visual, not textual, so the thing I was checking could not see it.
Fix
Compare delivered files visually against fixed templates, which made template stability measurable, and move the watcher off raw messages so the record holds an LLM written job definition instead of the mail body.

Rıfkı, a desktop robot

Working prototype · ESP32-S3

Voice in, voice and motion out: microphone to speech recognition to an LLM to speech synthesis to head and arm servos, with wake word detection, over the air firmware updates and camera based face tracking. The power fault is in the case above; this one is the pipeline lying quietly.

Symptom
The speech pipeline kept inventing a phrase out of silence.
First guess
Filter the phrase. Rejected: that patches the wrong layer.
Root cause
Torch's C++ file open corrupts the Turkish character in the project path, so the voice activity detector raised on every call and a broad except turned that failure into a warning. With the detector dead, endpointing never fired and the transcriber was handed pure silence.
Fix
Copy the model file to an ASCII cache path through Python and load it from there.

guard-20, audit-20 and Mythos Scaffold

Open source · claude-audit-20 · claude-mythos-scaffold

Two skill sets that turn recurring AI coding failures into enforceable process. guard-20 loads before code is written and states twenty failure classes as writing rules. audit-20 runs at the end as a twenty pass verification gate whose final pass does nothing but try to falsify the findings of the previous nineteen, so the aggressive passes do not bury you in false positives. Mythos Scaffold externalises long task state into a mission file, enforces persistence through Stop and SessionStart hooks so an agent cannot quit early or lose the thread after context compaction, and routes work to named worker agents by model tier.

Symptom
The scaffold measurably degraded output on the newest model generation, the opposite of its purpose.
Root cause
Over scaffolding. The newer the model, the more the extra process costs it.
Fix
Model gating, the ceiling written into the documentation, and an eval harness that runs bare and scaffolded arms so the claim is measured rather than assumed.

Python · Claude Code skills · Stop and SessionStart hooks · eval harness

Cebimde Claude

iOS client for agentic development

An iPhone app that hands a task to a coding agent from anywhere: SwiftUI client, TypeScript backend on the Mac running the Claude Agent SDK, WebSocket between them. The agent produces either a web page or a full XcodeGen SwiftUI project, builds it, and returns a simulator screenshot; a second command installs it on a real device.

Symptom
On a phone the connection drops constantly, and every drop left a ghost: output and heartbeats going to a dead socket, reconnect storms, an abandoned agent still running while a new one started on the same project.
Root cause
No identity on the connection and no ownership rule per project.
Fix
A connection epoch so late output cannot reach a stale socket, a rule that a new message stops any hanging agent on that project, and session ids persisted to disk so a conversation survives the app being killed.
